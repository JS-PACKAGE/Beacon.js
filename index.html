遊戲大廳的訊號燈

先驗證身分、選定遊戲，再找到一起玩的房間。Beacon.js 專注於安全的連線、房間管理與即時通知，讓遊戲系統各司其職。

一個清楚分工的大廳後端

依遊戲找房間

選遊戲後才進入大廳，房間清單與推播按遊戲隔離。

密碼與人數上限

房間密碼以 scrypt 雜湊保存；人數上限由遊戲 API 提供，加入操作避免超額競態。

保留房間，不保留連線

SQLite 保存房間資料；重啟後在線成員清空，玩家需要重新連線與驗證。

安全是架構的一部分

對外使用 WSS，OAuth 經驗證 adapter 串接；搭配輸入驗證、配額、心跳、背壓與憑證遮蔽。介紹頁由 GitHub Pages 提供，與 WebSocket 服務分離。

Beacon.js 不提供帳號註冊、遊戲本體或前端大廳操作介面。

實作與上線是兩件事

這是靜態介紹頁，不是可操作的大廳。真實 OAuth 與外部 WSS 部署必須取得實際端點和驗收證據；本頁不宣稱服務已上線或驗收通過。

開發者請閱讀倉庫的 README、AGENTS 與完整 PLAN。發布與部署由使用者明確操作。
